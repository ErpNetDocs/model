# Table Wms_Warehouse_Process_Steps


## Entity

Entity: [Logistics.Wms.WarehouseProcessSteps](~/entities/Logistics.Wms.WarehouseProcessSteps.md)

Contains the ordered steps that define how a Warehouse Process is executed. The steps should be arranged in the sequence in which they are intended to run. Each step represents a specific stage of the process and defines the algorithm and Warehouse Order document type used for its execution. An optional condition can be specified for each step to determine whether it should be executed or skipped. Entity: Wms_Warehouse_Process_Steps (Introduced in version 27.1.1.51)
