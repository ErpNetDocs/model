# Table Gen_Product_Product_Types


## Entity

Entity: [General.Products.ProductProductTypes](~/entities/General.Products.ProductProductTypes.md)

Allows the same product to have a different product type for accounting in each enterprise company. If no company-specific mapping exists, accounting uses the product’s standard product type. Entity: Gen_Product_Product_Types (Introduced in version 27.1.1.79)
