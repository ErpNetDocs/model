# Table Sys_Scripts


## Entity

Entity: [Systems.Core.Scripts](~/entities/Systems.Core.Scripts.md)

Contains managed scripts, their parameter schemas, and execution settings. Entity: Sys_Scripts (Introduced in version 27.1.1.39)

## Summary

| Name | Type | Description |
| - | - | --- |
|[Execution_Settings](#execution_settings)|`nvarchar(max)` |JSON object specifying the script execution limits and settings.|
|[Is_Active](#is_active)|`bit` |Indicates whether the script can be executed.|
|[Notes](#notes)|`nvarchar(max)` |Additional information about the script.|
|[Parameters_Schema](#parameters_schema)|`nvarchar(max)` |JSON schema describing the script parameters and return value.|
|[Row_Version](#row_version)|`timestamp` |Database-managed value used for optimistic concurrency control.|
|[Script_Code](#script_code)|`nvarchar(16)` |Unique code used to identify the script.|
|[Script_Id](#script_id)|`uniqueidentifier` `PK`|Unique identifier of the script.|
|[Script_Language](#script_language)|`nvarchar(16)` Allowed: `JavaScript`|Programming language of the script.|
|[Script_Name](#script_name)|`nvarchar(254)` |Display name of the script.|
|[Script_Text](#script_text)|`nvarchar(max)` |Source code of the script.|
