# R35899-6 Case - Assigned To User From New Development
| Name | Value |
| ---- | ----- |
| Code | R35899-6 |
| Entity | @Projects.Agile.Cases |
| Name | AssignedToUserFromNewDevelopment |
| Attribute | AssignedToUser |
| Layer | Back-End |
| Events | Aggregate Commit |
| Record State | On-Insert/Update |
| Priority | Normal |
| Modify | Yes |
| Action | For each currently added Case Development of the Case: <br/>If (CaseDevelopment.AssignedToUser != NULL) <br/>then <br/>Case.AssignedToUser = CaseDevelopment.AssignedToUser |
| Description| When a new Case Development is created, the AssignedToUser is set in the Case's AssignedToUser field. |
| Message | - |
