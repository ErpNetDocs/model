# R101977-2 Sale - Clear Inapplicable Service Profile

+----------------------+----------------------------------------------------------------------------------------------------+
| **Code**             | R101977-2                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Entity**           | @Crm.Pos.Sales                                                                                     |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Name**             | ClearInapplicableServiceProfile                                                                    |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Attribute**        | Location, Terminal, ServiceProfile                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Layer**            | Front-End                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Events**           | AttributeChanged(Location, Terminal)                                                               |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Priority**         | Normal                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Modify**           | YES                                                                                                |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Action**           | Clear an inapplicable service profile when the sale location changes. For a new sale,              |
|                      | assign the terminal's default service profile if it is active and applicable.                      |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Description**      | When the sale location changes, an inapplicable service profile is cleared.                        |
|                      | When a terminal is selected for a new sale, its active and applicable default service profile      |
|                      | is assigned if no profile is already selected.                                                     |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Message**          | N/A                                                                                                |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Version**          | Introduced: v.27.1                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Revocable**        | YES                                                                                                |
