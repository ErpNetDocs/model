# R101985 Object - Nested Object Creation Not Allowed

| **Code** | R101985 |
| --- | --- |
| **Entity** | @Systems.Core.ExtensibleDataObjects |
| **Name** | NestedObjectCreationNotAllowed |
| **Attribute** | EntityType |
| **Layer** | Back-End |
| **Events** | Commit |
| **Record State** | Inserted |
| **Priority** | Normal |
| **Modify** | NO |
| **Applicable Legislations** | [ALL // no condition needed](xref:applicable-legislations) |
| **Action** | For a new ExtensibleDataObject (`ObjectState = Added`), validate that `EntityType` is not `Sys_Objects`. The comparison is case-insensitive. |
| **Description** | An ExtensibleDataObject holds metadata for an aggregate root. An ExtensibleDataObject is its own metadata object and must not have another ExtensibleDataObject attached to it.<br/><br/>The rule rejects the creation of nested ExtensibleDataObjects at server Commit, including creation initiated by a client application or by server-side code.<br/><br/>Existing historical nested records pass this rule when updated. They are not modified or deleted by the rule, and all other applicable validations still run. |
| **Message** | An ExtensibleDataObject cannot be created for another ExtensibleDataObject. |
| **Version** | Introduced: v.26.3 |
| **Revocable** | NO |
