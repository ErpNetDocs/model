If a mapping exists, set LineProductType to its ProductType. Otherwise, set it to Product.ProductType. |
| <strong style="white-space: normal; overflow-wrap: normal; word-break: normal; hyphens: none;">Description</strong> | Sets the default product type for a logistic document line according to the document's enterprise company. This allows the same product to be classified differently by different enterprise companies. When no company-specific mapping exists, the product's standard type is used. The activating system key is to be defined. |
