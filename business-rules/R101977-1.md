# R101977-1 Service Profile - ClearLocationGroupAndLocation

+----------------------+----------------------------------------------------------------------------------------------------+
| **Code**             | R101977-1                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Entity**           | @Crm.Pos.ServiceProfiles                                                                           |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Name**             | ClearLocationGroupAndLocation                                                                      |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Attribute**        | EnterpriseCompany, LocationGroup, Location                                                         |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Layer**            | Front-End                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Events**           | AttributeChanged(EnterpriseCompany, LocationGroup)                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Priority**         | Normal                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Modify**           | YES                                                                                                |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Action**           | When EnterpriseCompany changes, clear both LocationGroup and Location.                             | 
|                      |  When LocationGroup changes, clear only Location.                                                  |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Description**      | When `EnterpriseCompany` changes, set `LocationGroup` and `Location` to NULL. When `LocationGroup` |
|                      | changes, set `Location` to NULL. The rule executes on attribute changes, not when an existing      |
|                      | service profile is loaded.                                                                         |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Message**          | N/A                                                                                                |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Version**          | Introduced: v.27.1                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Revocable**        | YES                                                                                                |
+----------------------+----------------------------------------------------------------------------------------------------+
*Revocable is enabled through `RegisterRevocableRuleForAttributeChanged` in `FrontEndServiceProfilesRepository`.*
