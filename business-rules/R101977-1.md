# R101977-1 Service Profile - Clear Dependent Hierarchy
+----------------------+----------------------------------------------------------------------------------------------+
| **Code**             | 39256-3                                                                                      |
+----------------------+----------------------------------------------------------------------------------------------+
| **Entity**           | @Crm.Pos.ServiceProfiles                                                                     |
+----------------------+----------------------------------------------------------------------------------------------+
| **Name**             | ClearDependentHierarchy                                                                      |
+----------------------+----------------------------------------------------------------------------------------------+
| **Attribute**        | Multiple                                                                                     |
+----------------------+----------------------------------------------------------------------------------------------+
| **Layer**            | Front-End                                                                                    |
+----------------------+----------------------------------------------------------------------------------------------+
| **Events**           | AttributeChanged(EnterpriseCompany, LocationGroup)                                           |
+----------------------+----------------------------------------------------------------------------------------------+
| **Priority**         | Normal                                                                                       |
+----------------------+----------------------------------------------------------------------------------------------+
| **Modify**           | YES                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------+
| **Applicable         | [ALL // no condition needed](xref:applicable-legislations)                                   |
| Legislations**       |                                                                                              |
+----------------------+----------------------------------------------------------------------------------------------+
| **Action**           | Cascade reset downstream attributes to NULL.                                                 |
+----------------------+----------------------------------------------------------------------------------------------+
| **Description**      | Maintains the integrity of the POS hierarchy by clearing child selections when a parent      |
|                      | property is modified. The logic follows a strict top-down cascade:                           |
|                      |                                                                                              |
|                      | 1. If EnterpriseCompany changes: PosLocationGroup and PosLocation are set to NULL.           |
|                      | 2. If PosLocationGroup changes: PosLocation is set to NULL.                                  |
+----------------------+----------------------------------------------------------------------------------------------+
| **Message**          | 27.1                                                                                         |
+----------------------+----------------------------------------------------------------------------------------------+
| **Version**          |                                                                                              |
+----------------------+----------------------------------------------------------------------------------------------+
| **Revocable**        | YES                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------+
