# R101958 Warehouse Policies - Next Temporary LUN Value

| Name | Value |
| ---- | ----- |
| Code | R101958 |
| Entity | @Logistics.Wms.WarehousePolicies |
| Name | NextTemporaryLUNValue |
| Attribute | Value |
| Layer | Back-End |
| Events | Commit |
| Priority | Normal |
| Modify | NO |
| Applicable Legislations | ALL // no condition needed |
| Action | If PolicyKind == NextTemporaryLUN, then validate that Value:<br> - is not empty;<br> - does not contain spaces;<br> - ends with one or more digits. |
| Description | Validates the Value field of warehouse policies of kind “Next Temporary LUN”. The value specifies the next temporary LUN and must end with a numeric part, which is used as an incrementing counter. |
| Message | Field {Value} contains an invalid value.<br> The selected value {value} is invalid for a warehouse policy of kind {warehouse policy}.<br> The value must end with a number and must not contain spaces, for example “1”, “TEMP1”, or “PACK-100”. |
| Introduced In Version | |
| Revocable | NO |
