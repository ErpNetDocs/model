# R101789 Customer - Set Allow Use As Primary Customer Or Ship To Customer
+-----------------------------+---------------------------------------------------------------------------------------+
| **Code**                    | R101789                                                                               |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Entity**                  | @Crm.Sales.Customers                                                                  |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Name**                    | SetAllowUseAsPrimaryCustomerOrShipToCustomer                                          |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Attribute**               | [Allow Use As Primary Customer](../entities/Crm.Sales.Customers.md#allowuseasprimarycustomer)|
|                             | [Allow Use As Ship To Customer](../entities/Crm.Sales.Customers.md#allowuseasshiptocustomer)|
+-----------------------------+---------------------------------------------------------------------------------------+
| **Layer**                   | Front-End                                                                             |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Events**                  | AttributeChanged(Party)                                                               |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Priority**                | Normal                                                                                |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Modify**                  | YES                                                                                   |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Action**                  | IF Party.PartyType = Person OR Party.PartyType = Company                              |         
|                             |        SET AllowUseAsPrimaryCustomer = true                                           |
|                             | IF Party.PartyType = CompanyLocation                                                  |
|                             |        SET AllowUseAsShipToCustomer = true                                            |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Description**             | When creating a new Customer, the AllowUseAsPrimaryCustomer is set to true if         |
|                             | Party Type is Company or Person, and the AllowUseAsShipToCustomer is set to true      |
|                             | if Party Type is CompanyLocation.                                                     |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Message**                 | \-                                                                                    |                         
+-----------------------------+---------------------------------------------------------------------------------------+
| **Version**                 | Introduced: v.27                                                                      |
+-----------------------------+---------------------------------------------------------------------------------------+
| **Revocable**               | YES                                                                                   |
+-----------------------------+---------------------------------------------------------------------------------------+
