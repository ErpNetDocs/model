# R35899-7 Case - System State From New Development
| Name | Value |
| ---- | ----- |
| Code | R35899-7 |
| Entity | @Projects.Agile.Cases |
| Name | SystemStateFromNewDevelopment |
| Attribute | SystemState |
| Layer | Back-End |
| Events | Aggregate Commit |
| Record State | On-Insert/Update |
| Priority | Normal |
| Modify | Yes |
| Action | For each currently added Case Development of the Case: <br/>If (CaseDevelopment.NewSystemState != NULL) <br/>then <br/>Case.SystemState = CaseDevelopment.NewSystemState |
| Description| When a new Case Development is created, the NewSystemState is set in the Case's SystemState field. |
| Message | - |

| Revocable | YES |
