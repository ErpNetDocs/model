# R101977-9 Terminal - Default Service Profile Applicable
+----------------------+----------------------------------------------------------------------------------------------------+
| **Code**             | R101977-9                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Entity**           | @Crm.Pos.Terminals                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Name**             | DefaultServiceProfileApplicable                                                                    |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Attribute**        | DefaultServiceProfile, PosLocation                                                                 |  
+----------------------+----------------------------------------------------------------------------------------------------+
| **Layer**            | Back-End                                                                                           |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Events**           | Commit                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Record State**     | Inserted, Updated                                                                                  |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Priority**         | Normal                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Modify**           | NO                                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Applicable         | [ALL // no condition needed](xref:applicable-legislations)                                         |
| Legislations**       |                                                                                                    |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Action**           |Validate that the default service profile is applicable to the terminal's POS location.             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Description**      | When the default service profile or POS location changes, the selected profile must be applicable  |
|                      | to the terminal location. Only specified profile restrictions are checked. If the profile          |
|                      | is selected but the location is missing, validation fails.                                         |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Message**          | The selected default service profile is not applicable to the POS terminal location.               |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Version**          | Introduced: v.27.1                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Revocable**        | NO                                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
