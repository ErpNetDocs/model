# R101977-7 Sale - Service Profile Is Applicable

+----------------------+----------------------------------------------------------------------------------------------------+
| **Code**             | R101977-7                                                                                          |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Entity**           | @Crm.Pos.Sales                                                                                     |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Name**             | ServiceProfileIsApplicable                                                                         |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Attribute**        | ServiceProfile, Location                                                                           |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Layer**            | Back-End                                                                                           |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Events**           | Commit                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Record State**     | Inserted, Updated                                                                                  |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Priority**         | Normal                                                                                             |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Modify**           | NO                                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Applicable         | [ALL // no condition needed](xref:applicable-legislations)                                         |
| Legislations**       |                                                                                                    |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Action**           | Validate that the selected service profile is applicable to the sale location.                     |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Description**      | When a service profile is selected, the sale location must be specified and match all defined      |
|                      | enterprise company, location group, and location restrictions.                                     |
|                      | Only specified restrictions are checked. If no service profile is selected, validation succeeds.   |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Message**          | The selected service profile is not applicable to the POS sale location.                           |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Version**          | Introduced: v.27.1                                                                                 |
+----------------------+----------------------------------------------------------------------------------------------------+
| **Revocable**        | NO                                                                                                 |
